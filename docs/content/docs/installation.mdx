## With gdsuite

[gdsuite](https://q-rault.github.io/gdsuite/) includes gdtypecheck, at the version it was tested with: installing gdsuite is enough, and its releases have a binary for each platform.

## Install from crates.io

Requires Rust 1.96 or later.

```sh
cargo install gdtypecheck
```

## Godot

gdtypecheck runs your project in a headless Godot 4.5 or later. It uses, in
order:

1. `--godot-exe <path>`
2. the `GODOT_EXE` environment variable
3. `godot` on the `PATH`

## Verify

Run it from your project root, next to `project.godot`:

```sh
gdtypecheck --version
gdtypecheck
```
