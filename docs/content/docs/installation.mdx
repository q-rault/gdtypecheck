## Download a release binary

Each [GitHub release](https://github.com/q-rault/gdtypecheck/releases) has a
binary for each platform, no Rust needed:

| Platform | Archive |
| --- | --- |
| macOS arm64 | `gdtypecheck-*-aarch64-apple-darwin.tar.gz` |
| macOS x86_64 | `gdtypecheck-*-x86_64-apple-darwin.tar.gz` |
| Linux x86_64 | `gdtypecheck-*-x86_64-unknown-linux-musl.tar.gz` |
| Windows x86_64 | `gdtypecheck-*-x86_64-pc-windows-msvc.zip` |

Put the `gdtypecheck` binary on your `PATH`. With [gdsuite](https://q-rault.github.io/gdsuite/),
`gdsuite setup` downloads the version it was tested with for you.

## Install from crates.io

Requires Rust 1.96 or later.

```sh
cargo install gdtypecheck
```

## Godot

gdtypecheck runs your project in a headless Godot 4.5 or later. It uses, in
order:

1. `--godot-exe <path>`
2. the `GODOT_EXE` environment variable
3. `godot` on the `PATH`

## Verify

Run it from your project root, next to `project.godot`:

```sh
gdtypecheck --version
gdtypecheck
```
